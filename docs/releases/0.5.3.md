# TomoNode 0.5.3

選定済みのTomoNodeアイコンをアプリとWindows向け配布物へ反映する更新です。

## 変更内容

- タイトルバーに選定済みのロゴを表示します。ダークテーマでは黒背景版、ライトテーマでは白背景版を使用します。systemテーマでは解決後のテーマに合わせて切り替わります。
- テーマ設定が未保存の場合の初期値をダークにします。保存済みのユーザー設定はそのまま尊重します。
- Windowsのアプリ、タスクバー、スタートメニュー、NSISインストーラー、アンインストーラーに黒背景版アイコンを使用します。
- アプリ識別子、インストール先、Updater公開鍵、更新フィードURL、既存のユーザーデータ形式は維持します。

## 確認状況

- ダーク、ライト、systemテーマでタイトルバーロゴを確認します。
- Windows向けインストーラー生成時に選定済みの黒背景版ICOを参照します。
- GitHub ActionsはWindowsインストーラーとTauri Updater署名を作成し、公開前後に配布物を検証します。
