# TomoNode 0.5.4

Windows installer branding and shortcut names now use TomoNode while retaining compatibility with existing installations.

## Changes

- The setup and uninstaller windows, including welcome, install location, progress, and finish pages, display TomoNode.
- The Windows setup file's ProductName and FileDescription metadata, and its "Open with" label, use TomoNode.
- New Start Menu and desktop shortcuts use the TomoNode name and the installed executable as their icon source.
- During an upgrade, the installer renames an old shortcut only when it points to this installation. A same-named shortcut owned by another app is preserved.
- Existing installation paths, Windows installation identity, updater public key and feed, and user data format remain unchanged.
