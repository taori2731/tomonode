# TomoNode 0.5.17

会員資格の「接続準備中」を通信失敗と誤表示しないための更新です。アプリ更新とSupporterの販売開始は別工程です。

## 変更内容

- 固定の資格APIが、課金接続未準備を示す所定の503応答を返した場合は「会員資格の接続準備中」と表示します。
- 手動の会員状態再確認でも、準備中を通信失敗として警告しません。その他の通信・署名・時刻の問題は従来どおり失敗として扱います。
- 署名資格の検証処理を独立モジュールへ整理しました。署名、セッションとの結び付け、支払済み期限、最大24時間、live/testの判定条件は維持しています。
- 更新案内を9言語で今回の内容に合わせ、0.5.16の案内も残しました。

## 配布・販売の境界

- 新規購入受付は引き続き無効です。この更新は購入や有料資格を有効にしません。
- 無料機能、保存形式、アプリ識別子、更新URL、署名公開鍵は変更しません。
- 所定の準備中応答だけでSupporter資格を付与しません。既存の有効な署名資格は、期限を延長せず従来のオフライン判定で扱います。
- 更新用署名とWindowsの発行元証明（Authenticode）は別です。本候補は更新用署名を検証済みですが、Authenticode署名はありません。
- インストール済みアプリの更新後動作と、有料特典の本番受入は別途確認が必要です。
