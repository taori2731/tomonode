# TomoNode 0.4.5

Forge Modの依存関係検査で発生していた誤判定を修正する更新です。

## 修正内容

- Forge／NeoForgeの`mandatory=false`依存を必須エラーとして扱わないようにしました。
- 専用サーバーに不要な`side="CLIENT"`依存を起動ブロック対象から除外しました。
- `META-INF/jarjar/`に同梱されたModを依存解決の存在確認へ含めました。
- PuzzlesLibに同梱されたPuzzles Access APIを不足扱いしない回帰テストを追加しました。
- GeckoLibの任意依存GeckoAnimFixを必須不足として扱わない回帰テストを追加しました。

## 互換性

- 既存のアプリ識別子、保存先、Updater公開鍵は変更していません。
- 更新フィードは名称変更後の`taori2731/tomonode-releases`を使用し、インストーラー資産名を`TomoNode_0.4.5_x64-setup.exe`へ統一しました。
- サーバーフォルダー、ワールド、Mod、バックアップ、管理マニフェストの形式は変更していません。

## 更新後の確認

更新後に安全ツールのMod／プラグイン検査を再実行し、実際のForgeサーバーが不足依存の誤判定なしで起動することを確認してください。
