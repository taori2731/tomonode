# TomoNode 0.5.1

## 概要

コンソールログの固定行数上限を解除した、0.5.0からの互換パッチリリースです。インストール済みの0.5.0から、アプリ内Updaterで更新できます。

## 変更内容

- コンソールUIで最新500行に切り詰めず、取得できたログ履歴を検索・コピー・保存できるようにしました。
- Rust側のコンソール保持上限5,000行を解除しました。
- IPCで返すログを末尾1,000行へ制限する処理を解除しました。
- 長時間のコンソール表示でも、ログの追加をバッチ処理し、既存行の再描画を抑えます。
- 既存のサーバー設定、保存データ、バックアップ、友達招待などの機能は変更していません。

## 更新方式

- Tauri Updaterの公開鍵と公式更新フィードは従来のままです。
- 更新マニフェストと隣接`.sig`は、既存のTauri Updater署名方式で検証されます。
- Windows Authenticode署名やSignPathを、このアプリ内Updaterの必須条件にはしていません。
- 0.5.0 Releaseは履歴として保持し、0.5.1を新しいReleaseとして公開します。

## 注意

ログを長時間保持すると、表示・検索・保存のためにメモリを多く使う場合があります。不要なログは、必要に応じて保存したうえでコンソールのクリア操作を使用してください。
