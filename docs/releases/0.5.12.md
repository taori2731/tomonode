# TomoNode 0.5.12

## Changes

- Free manages up to three registered servers across creation, existing-folder import and migration import. Existing servers above the cap remain usable; worlds, settings and backups are not deleted or disabled.
- Account and app settings share a green Free / navy-purple Supporter comparison. The planned Supporter price is JPY 500/month; public enrollment remains disabled.
- Adds native signed-qualification verification, three exclusive theme previews, optional preview settings and a Discord operational-notification implementation with secret storage and explicit opt-in. No ready preview feature is currently offered.
- Preserves browser sign-in, automatic sign-in after account creation and verification, display-name and avatar editing, actual user ID/date, verified email changes, readable light-theme account pages and the TomoNode default server icon.

## Preparation boundaries

- Supporter qualification is not activated in this release. The membership public-key pin is intentionally empty. No production Stripe payments, remote account-API changes, database migrations, new secrets or real Discord test sends are included.
- Theme application, preview activation and Discord sends require a verified Supporter qualification, not a local flag. Only previews and preparation status are available until the service is separately configured and validated.
- The updater public key, application identifier and release endpoint remain unchanged.
- Public artifact verification is separate from installed-Windows update acceptance. The user performs the update UI and real-account sign-in checks.
