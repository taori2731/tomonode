# TomoNode 0.5.8

## Changes

- Moves the account entry to the lower-left sidebar and opens a compact profile menu with account, plan, and security sections.
- Adds profile display-name and avatar controls. Account creation and password-related actions require the account service and may remain unavailable until its configuration is complete.
- Uses the supplied TomoNode image as the default server icon in the sidebar, home card, and server overview. Existing custom server images are preserved.
- Removes the in-app advertising placeholders. Website advertising is separate and remains subject to AdSense review.

## Update notes

- The updater public key, application identifier, and release endpoint remain unchanged.
- The installed app's update detection and profile behavior should be checked separately after publication.
