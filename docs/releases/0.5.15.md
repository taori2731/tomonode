# TomoNode 0.5.15

支払い通知が遅れた場合に、アプリから会員状態を明示的に再確認するための更新候補です。公開済み0.5.14の成果物は差し替えません。更新版の配布とSupporterの販売開始は別工程です。

## 変更内容

- 「会員状態を再確認」から、ログイン中のアカウントに紐づく支払い状態の照合を要求します。起動時や定期更新では、この追加照合を自動実行しません。
- 照合の成功応答だけでSupporterを付与せず、その後にセッションへ紐づいた署名資格を取得・検証します。
- 再確認に失敗すると購入・契約管理を止め、手動再試行が成功すると復帰します。認証失効・返金等の保留が返った場合は古い資格キャッシュを破棄します。
- 通信中の連打、画面を閉じた後の処理、アカウント切り替え後に古い応答が別のアカウントへ反映されるケースを対策します。
- 認証トークンはネイティブ側だけで扱い、Reactへ返しません。照合先を許可したAPIへ限定し、HTTPリダイレクトを拒否します。

## 販売・配布の状態

- この候補の `supportConfig.enabled` と公開APIの `BILLING_ENABLED` は無効のままです。販売開始、実アカウントへの特典付与、本番購入の受入完了を意味しません。
- 料金の案内は月額USD3.00＋適用税。規約・販売地域と税方針を確定し、本番購入から資格反映・契約管理・解約まで確認してから受付を開始します。
- 更新用公開鍵、アプリ識別子、既存更新フィードを維持します。実アカウントのサーバーやプロフィールを変更する移行は追加しません。
- 署名済みNSIS・更新manifest・SHA-256の検証と、インストール済みアプリの更新・データ維持の受入は別工程です。既存タグ・Releaseの上書きは禁止します。
- 独立検証ラボの仮アカウント・秘密情報・DBを同梱しません。テスト資格はreleaseでは受け付けません。

技術的な設定と停止条件は [購入API設定ガイド](../../cloudflare/account-api/SETUP.md) を参照してください。
