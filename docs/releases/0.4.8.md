# TomoNode 0.4.8

サーバー起動中や通常操作でアプリが重くなり、「応答なし」になりやすい経路を軽量化する更新です。0.4.7で行ったログ表示の軽量化を維持し、起動前検査・ステータス取得・プレイヤー検出・Reactの更新処理を追加で見直しました。

## 修正内容

- サーバー起動と再起動の起動前診断、Mod／プラグイン検査、ポート確認、プロセス生成をblocking poolへ移し、Tauriの非同期実行系と画面操作を塞がないようにしました。
- Minecraftのステータス取得に含まれていたTCP／UDP ping、sysinfo更新、ログ解析をblocking poolで実行するようにしました。
- ステータス探査結果を短時間キャッシュし、同じサーバーへの探査が重複して走らないようにしました。キャッシュ中や探査中は既存値または安全な起動中状態を即時返します。
- オンラインプレイヤーのログ検出を、セッション開始位置からの全再走査ではなく前回位置からの差分走査へ変更しました。保持ログがローテーションした場合はアンカー不一致を検出して安全に再構築します。
- Reactのステータス・ログ反映を低優先度の更新へ切り替え、画面移動や入力操作を優先できるようにしました。タブ定義の不要な再生成も抑えています。
- 既存のBAN処理、Mod互換性検査、Iron's Spells 'n SpellbooksのLoot Table警告の分類、保存形式、Updater公開鍵、アプリ識別子は変更していません。

## 互換性

- 既存のアプリ識別子、Windowsの保存先、Updater公開鍵、公開フィードURLは変更していません。
- サーバーフォルダー、ワールド、Mod、バックアップ、管理マニフェストの形式は変更していません。
- プレイヤーのBAN処理は0.4.7の修正を維持します。
- この作業では実ユーザーのサーバーデータ、Credential Manager、ルーター設定を変更していません。

## 確認状況

- Rustのステータスキャッシュ、探査中の重複抑止、プレイヤーログ差分走査、ログローテーション復旧の回帰テストを追加しました。
- Rust `cargo check`、Rust全体テスト、TypeScript型検査、アプリテストを実行しています。
- 実際のインストール済み0.4.8への更新、実Forgeサーバーの長時間起動、Windowsでの「応答なし」が完全に解消したこと、実ユーザー環境でのパフォーマンスはこの資料作成時点では未確認です。
- 署名、GitHub Actions実行、公開Release、公開フィード、インストーラー更新は別のリリース工程で確認します。
