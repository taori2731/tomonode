# TomoNode 0.5.11

## Changes

- Completing account creation now signs in immediately after the initial email verification and password setup. Desktop access still requires explicit pairing approval.
- Profile, Security, and Plan use readable light-theme surfaces and text. Plan comparison preserves the deep-green Free and navy/purple Supporter cards in both themes; Supporter remains preparation-only with no announced price or payment integration.
- Profile displays the actual stable account ID and creation date, with an ID copy button. Display-name editing and synchronized avatars remain available.
- Email changes require the current password and a confirmation link sent to the new address. Completion invalidates earlier sessions and pending desktop grants without changing the account identity, avatar, or subscription records.
- Removed the unfinished device list, other-device logout control, and extra account-preferences subpage. Normal logout remains available.

## Update notes

- The updater public key, application identifier, and release endpoint are unchanged.
- Account API migration 0004 is additive and must be applied before deploying the matching Worker.
- Mocked browser tests and SQLite fault-injection checks do not replace real-mail or installed-Windows update acceptance.
