# TomoNode 0.5.10

## Changes

- Signed-out account access now starts login or account creation in the browser. The app displays a short-lived pairing code, can reopen the browser, and can cancel the request.
- The app keeps the browser authorization verifier in native memory, polls the account service natively, and stores a completed session in Windows Credential Manager.
- Password setup from Security opens browser registration when the profile has no password. Profile, Security, Plan, display-name, and avatar controls remain in the app.
- Password requirements are 6–128 Unicode code points and at most 512 UTF-8 bytes in every supported locale.

## Update notes

- The updater public key, application identifier, and release endpoint remain unchanged from 0.5.9.
- The guarded signing workflow checks the account API typecheck and regression suite alongside the desktop checks.
- Automated checks and browser-service checks do not confirm installed-app update behavior or live Windows account acceptance. Those still require verification in the installed Windows app.
