# TomoNode 0.5.7

## Account sign-in

- Adds email verification code sign-in for the installed Windows app.
- Stores the opaque account session in Windows Credential Manager.
- Keeps the account service URL restricted to the configured HTTPS host.
- Subscription checkout and billing management are not enabled in this release.

## Notes

- The app updater public key and release endpoint are unchanged.
- Confirm in-app update detection and installed-app behavior separately.
