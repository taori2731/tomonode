# TomoNode 0.5.0

サーバー稼働中の画面操作と、長時間開いたコンソールの負荷を抑える軽量化更新です。保存データ、サーバー操作、既存のUI構成は変更していません。

## 修正内容

- 同じ内容のログ取得結果を、最大1000件の履歴全体を毎回比較せず再利用するようにしました。末尾が変わった場合は従来どおり完全比較へ戻るため、変更検出の正しさは維持します。
- コンソールの最新500行表示は維持したまま、ログ内容に基づく安定した行キーを使い、新しい行の追加で既存行を再マウントしないようにしました。
- ニュース、テンプレート、発見などサーバー操作を表示していない画面では、背景サーバーの状態IPC監視を停止し、サーバー画面へ戻ったときに再開するようにしました。
- ホームのサーバーカードは、表示に関係する状態が変わったカードだけを再描画するようにしました。
- Palworldのプレイヤー情報を含む状態比較で`JSON.stringify`を使わず、既存の項目を直接比較するようにしました。
- 起動時に必要な監視設定の読み取りと警告計算を重い設定パネルから分離し、設定パネル本体を初期JavaScriptへ取り込まないようにしました。
- 9言語のアプリ内ニュースを0.5.0の実装内容へ更新しました。

## 互換性

- アプリ識別子、Windowsの保存先、Updater公開鍵、更新フィードURLは変更していません。
- サーバーフォルダー、ワールド、Mod、バックアップ、SQLite、Credential Manager、`.mshmove`、Profile JSONの形式は変更していません。
- コンソールの表示上限500行、Rust側のログ保持、サーバー固有のMinecraft／Palworld機能は維持しています。

## 確認状況

- `npm run check`、対象回帰テスト、全TypeScriptテスト（389件）、`npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml`を実行しました。
- 6倍CPUスロットルのUI性能smokeを単独実行し、12画面切替、長時間タスク500ms超なしのPASSを確認しました。最終実行は最長切替1,621ms、最長タスク277msでした。同時実行時には環境負荷で508msのタスクが1回発生したため、性能値は単独実行を採用しています。
- 変更前の同じsmoke基準は最長切替1,524ms、最長タスク286msでした。実行環境の初回変換・負荷差があるため、0.5.0での数値改善率は断定していません。
- production buildの初期JavaScriptは約406.44 kB（gzip約127.58 kB）で、設定パネル分離前の約418.14 kB（gzip約130.58 kB）から約11.7 kB（gzip約3.0 kB）減り、既存の450 KiBゲート内です。
- Windows x64 NSISインストーラー、Tauri Updater署名、埋め込み公開鍵検証、SHA-256、Draft再取得検証、Latest公開後の再取得検証は、GitHub Actionsの0.5.0リリースWorkflowでPASSしました。
- Windows Authenticode署名はこのリリースの必須条件ではなく、確認していません。SmartScreenが警告を表示する可能性があるため、実行前に公式Release、ファイル名、SHA-256、発行元情報を確認してください。
- 実サーバー稼働中のCPU／メモリ／GPU、長時間実機メモリ推移、別のクリーン環境での0.4.9からのUpdater画面操作は、今回の自動Release検証の対象外です。
