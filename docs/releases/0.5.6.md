# TomoNode 0.5.6

## 起動診断の誤判定修正

- NeoForgeなどが専用サーバー上でクライアント用クラスを検査したときに出す `invalid dist DEDICATED_SERVER` のクラス探索ログを、単独では起動失敗として扱わないようにしました。
- このログがReady到達前後に出ても、自動停止要求を送らないようにしました。
- Ready到達前の実際の異常終了、ModLoadingException、依存関係エラー、重複Modなどの確かな致命エラーは従来どおり失敗として扱います。
- 0.5.5以前に保存された誤判定履歴も、Ready到達の証拠と終了コード0があり、別の致命エラーがなければ診断画面で警告として再評価します。履歴ファイルやModは自動変更しません。

## Modローダー判定

- JAR内のメタデータの並び順に依存せず、現在のサーバーのローダーに対応する `fabric.mod.json`、`META-INF/mods.toml`、`META-INF/neoforge.mods.toml` を確認します。
- 複数ローダー用のメタデータを含むJARを、先に見つかった別ローダー向け情報だけで誤警告しないようにしました。

## 注意

このリリースには診断ロジックと回帰テストの修正が含まれます。実際のMod構成でのサーバー起動・プレイヤー参加の確認は、更新後に利用者側で行ってください。
