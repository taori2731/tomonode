# TomoNode 0.5.18

ログイン後のプラン確認・Stripe契約管理への接続を有効にしました。

- 新規購入は、サーバーが購入受付を明示的に許可した場合だけ利用できます。決済画面を開く直前にも再確認します。
- この更新だけでは販売を開始せず、支払いが確認されていないアカウントへSupporter特典を付与しません。
- 無料機能、サーバー・プロフィールの保存データ、署名検証、本番とSandboxの分離は維持します。
- 9言語の更新案内を追加し、0.5.17以前の履歴も残しました。

Enable account plan connectivity after login. Purchases still require explicit server permission; this update alone does not start sales or grant paid benefits. Free features, saved data and security checks remain unchanged.

The installer includes a Tauri updater signature. This is distinct from Windows Authenticode certification.
