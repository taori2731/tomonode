課金受付と本番Supporter資格発行は無効のままです。独立検証ラボは開発用スクリプトと `cfg(test)` コードだけに存在し、配布アプリの資格や接続先を変更しません。

署名付きインストーラー作成・公開フィード更新・インストール済みアプリでの受入は別工程で、本文の存在は配信成功を意味しません。既存0.5.12の公開資産は上書きしません。
