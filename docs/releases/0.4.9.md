# TomoNode 0.4.9

画面切替時の負荷を抑え、アプリ内の「更新情報とお知らせ」を実際のリリース内容へ同期する更新です。0.4.8のバックエンド軽量化を維持し、今回はフロントエンドの初期読み込み、DOM翻訳、ポーリング、再描画を見直しました。

## 修正内容

- アプリ内ニュースを0.4.9、0.4.8、0.4.7の実際の変更内容へ更新しました。
- ニュースの現在版と`package.json`の版が一致しない場合にテストを失敗させ、今後の版上げでニュース更新を忘れないようにしました。
- 日本語は画面の原文言語であるため、不要だったDOM全走査とMutationObserverによる翻訳監視を実行しないようにしました。
- 日本語以外では、タブ切替で追加されたDOMをその場で何度も翻訳せず、重複をまとめて一度画面を描画した後に翻訳します。翻訳結果には上限付きキャッシュを追加しました。
- 大きなDOM翻訳モジュールとPalworld専用文言を必要になるまで読み込まないようにし、初期JavaScriptを約559 KBから約415 KBへ削減しました（0.4.8比で約26%削減）。
- サーバー画面を離れてニュース、テンプレート、発見などを見ている間は、選択中サーバーの状態確認を10秒間隔へ抑え、ログ取得を停止します。
- サーバー画面では、起動中などの遷移状態を1秒、通常の起動中状態を2秒、停止中を5秒間隔で確認します。概要のログは5秒、コンソールのログは2秒間隔です。
- 背景サーバーの状態確認を15秒間隔へ変更しました。
- タブとセクションの切替をReactのTransitionで処理し、ユーザー入力をポーリング更新や重い画面生成より優先します。
- サイドバー、検索、ニュース、テンプレート、発見、バックアップ／診断、アクセスログで不要な再描画を抑えました。
- 初期JavaScriptを450 KiB以下へ保つビルドゲートと、6倍CPUスロットルで主要12画面を切り替える性能スモークテストを追加しました。

## 互換性

- 既存のアプリ識別子、Windowsの保存先、Updater公開鍵、公開フィードURLは変更していません。
- サーバーフォルダー、ワールド、Mod、バックアップ、管理マニフェストの形式は変更していません。
- 0.4.7のBAN修正と0.4.8の起動・状態取得・ログ差分走査の軽量化を維持します。
- ニュースはアプリに同梱するため、ネットワーク接続がなくても表示できます。

## 確認状況

- TypeScript型検査、アプリ全体テスト、9言語UIスモーク、production buildを実行しています。
- 1280×720のChromiumを6倍CPUスロットルにし、主要12画面の初回／再切替を検証しました。最終検証の最長切替は1,628 ms、最長メインスレッドタスクは333 msで、500 ms超の長時間タスクは0件でした。
- 初期JavaScriptは約559 KBから約415 KBへ減り、450 KiBのビルド上限内です。
- この数値はブラウザUIの再現環境による証拠です。実際の低スペックWindows PC、インストール済みTauriアプリ、実サーバー起動中の操作感を普遍的に保証するものではありません。
- パッケージ作成、Updater署名、GitHub Release公開、インストール済みアプリへの更新は別のリリース工程です。
