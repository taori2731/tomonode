# TomoNode 0.4.6

Forge Dedicated Serverでクライアント専用Modを入れた場合の検出・診断を強化する更新です。

## 修正内容

- `invalid dist DEDICATED_SERVER`とMod IDを含むForgeの起動ログから、クライアント専用Modの失敗を特定できるようにしました。
- Forge／NeoForge／Fabricのサーバー用Mod検査で、JAR内のクライアント専用マーカーを検出し、起動前にMod名と対処方法を提示するようにしました。
- 通常の起動だけでなく、再起動でも同じMod検査を適用するようにしました。
- RPG-HUDのクライアント専用失敗と、明示的なクライアント専用マーカーの回帰テストを追加しました。

## 互換性

- 既存のアプリ識別子、保存先、Updater公開鍵は変更していません。
- サーバーフォルダー、ワールド、Mod、バックアップ、管理マニフェストの形式は変更していません。
- この作業では公開、署名、インストール、実ユーザーのサーバーデータ変更を行っていません。

## 更新後の確認

更新後に安全ツールのMod検査を再実行し、対象Modを専用サーバー対応版へ置き換えるか、クライアント側だけへ移動してから実際のForgeサーバーを起動してください。パッケージ作成、署名、公開フィード、インストール済みアプリの更新、実サーバーのランタイム受入れはこの作業では未確認です。
