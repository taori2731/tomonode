# TomoNode 0.5.14

既存0.5.13 Draftの成果物は差し替えず、購入連携を含む別バージョンとして配布します。実際の配布状態はGitHub Releaseで確認してください。更新版の配布とSupporterの販売開始は別工程です。

## 変更内容

- ログイン後にSupporterの購入または契約管理へ進むためのアプリ側連携を追加。購入直前にもAPIの受付状態を確認し、ログイン失効・受付停止・通信失敗時は安全に案内します。
- 購入と契約管理のURLはネイティブ側でStripeの許可ホストを検査。認証トークンはReactへ返しません。画面を閉じた後の購入URL起動や連打を抑止します。
- 購入後の戻り先は案内に限定し、戻ってきたことだけで資格を付与しません。資格は支払い確認に基づく署名をアプリが検証します。
- Supporter料金の表示は月額USD3.00＋適用税。9言語の受付確認・ログイン・通信エラー案内を追加。
- 0.5.13候補のDiscordメンション・9言語・ホストPCのタイムゾーンによる時刻表示を含みます。

## 販売・配布の状態

- この候補の `supportConfig.enabled` と公開APIの `BILLING_ENABLED` は無効のままです。購入可能、課金開始済み、実アカウントにSupporterが付与済みとは案内しません。
- 更新用公開鍵、アプリ識別子、既存更新フィードは変更しません。テスト用資格はreleaseでは受け付けず、独立検証ラボの仮アカウント・秘密情報・DBを同梱しません。
- 既存0.5.12公開版と0.5.13 Draftを上書きしません。署名済みNSIS・更新manifestの検証、公開許可、インストール済みアプリの受入は別工程です。
- 規約全体・プライバシー・販売者表示と税方針の確認、本番購入から資格反映・契約管理までの受入が終わるまで販売開始しません。

技術的な設定と停止条件は [購入API設定ガイド](../../cloudflare/account-api/SETUP.md) を参照してください。
