# TomoNode 0.5.9

## Changes

- The account entry opens a centered settings dialog with Profile, Security, and Plan tabs.
- Profile editing keeps the existing display-name and avatar synchronization. Images up to 20 MB can be selected; the app crops and compresses them before upload, while the service's 128 KiB storage limit remains in place.
- The Security tab distinguishes available password-reset and email-code sign-in actions from features that are still in preparation.
- The Plan tab shows the current Free plan. Supporter pricing, benefits, and payments are not yet available and are marked as in preparation.

## Update notes

- The updater public key, application identifier, and release endpoint remain unchanged from 0.5.8.
- Browser previews and automated tests do not replace checking update detection and installation in the installed Windows app.
