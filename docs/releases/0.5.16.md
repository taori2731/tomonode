# TomoNode 0.5.16

Supporterの新規購入と既存契約管理を分離する更新です。公開済み0.5.15の成果物は差し替えません。アプリ更新とSupporterの販売開始は別工程です。

## 変更内容

- 新規購入ボタンは、APIが購入受付を明示的に許可している場合だけ利用できます。受付停止中や情報欠落時は購入を開始しません。
- Stripeの購入ページを開く直前にも受付状態を再確認します。表示後に受付が停止した場合も、新規購入を開始しません。
- 新規販売が停止中でも、契約管理の接続が有効な既存会員は契約管理を利用できます。手動の会員状態再確認も、新規購入の許可とは分けて扱います。
- 更新案内を9言語で今回の内容に合わせました。認証トークンや署名資格の検証方式は変更しません。

## 配布・販売の境界

- 本番の新規購入受付は引き続き無効です。この更新だけでSupporterを購入できるようにはなりません。
- 無料機能、サーバー／プロフィールの保存形式、アプリ識別子、更新フィードと署名公開鍵は維持します。試験用の課金コード・架空アカウント・非公開資料・秘密情報は配布へ追加しません。
- 販売開始には日本の税務方針、販売国制御、本番での支払いから資格反映・契約管理までの確認が必要です。
- インストール済みアプリでの更新とデータ維持は、署名・配布ファイルの検証とは別に確認します。

設定と停止条件は [購入API設定ガイド](../../cloudflare/account-api/SETUP.md) を参照してください。
