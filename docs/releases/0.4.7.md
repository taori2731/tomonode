# TomoNode 0.4.7

オンラインプレイヤー管理、Forge系サーバーの起動診断、ログ表示性能、GitHub ActionsのNode.js 24対応をまとめた更新です。

## 修正内容

- Java／ForgeサーバーのオンラインプレイヤーBANボタンが`pardon`を送信していた不具合を修正し、`ban`として反映するようにしました。Bedrockの「許可から外す」は従来どおりallowlist解除として扱います。
- Iron's Spells 'n Spellbooks 1.20.1-3.16.3の`catacombs/crypt_loot`と`citadel/citadel_tomes`に関するLoot Table警告を、サーバー全体の起動失敗とは区別した互換性警告として診断します。第三者MODのJARを自動改変せず、公式対応版と依存関係の確認を案内します。
- Modded Forge起動時のログ大量出力でWindowsアプリが「応答なし」になりやすい経路を軽量化しました。未使用の1行ごとのTauriイベント送信を停止し、バックエンドの保存上限を維持したままUI取得を最新ログに限定します。
- コンソール表示を最新500件に制限し、コピー文字列はコピー操作時だけ生成します。検索・保存・クリア・コマンド入力は維持し、表示範囲を画面上で案内します。
- ステータス、ログ、バックグラウンド監視の重複リクエストを抑止し、ウィンドウ非表示中の重いポーリングを停止して再表示時に更新します。
- GitHub ActionsをSHA固定のままNode.js 24対応版へ更新し、ActionsのNode実行環境とワークフローのNode.jsを24へ揃えました。

## 互換性

- 既存のアプリ識別子、保存先、Updater公開鍵は変更していません。
- サーバーフォルダー、ワールド、Mod、バックアップ、管理マニフェストの形式は変更していません。
- ログはバックエンドで従来どおり最大5,000件を保持し、保存操作は保持分全体を対象にします。画面取得だけ最新1,000件、コンソール表示だけ最新500件に制限します。
- この作業では公開、署名、インストール、実ユーザーのサーバーデータ変更を行っていません。

## 更新後の確認

更新後にJava／Forgeサーバーを起動し、オンラインプレイヤーのBAN操作でサーバーコンソールに`ban <player>`が現れ、`banned-players.json`へ反映されることを確認してください。Iron's Spells 'n Spellbooksの警告が残る場合は、ワールドをバックアップしてからMinecraft 1.20.1・Forge対応の公式配布版とCitadel依存関係を確認してください。パッケージ作成、署名、公開フィード、インストール済みアプリの更新、実サーバーのランタイム受入れはこの作業では未確認です。
