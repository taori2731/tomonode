# 0.5.16の公開前確認

確認日：2026-10-08。0.5.15を置き換える新しいアプリ更新候補です。既存タグ・Release・署名鍵を上書きせず、Supporter本番購入は引き続き無効にします。

## 変更の範囲

新規購入の明示許可、既存契約管理との分離、クリック直前の再確認、対応するテストと9言語の更新案内が対象です。アプリ識別子、updaterの公開鍵・フィード、保存形式は維持します。ローカルで進めている試験用のWorker変更、架空アカウント、非公開の法律原稿・運用記録は含めません。

## 配布の停止点

1. アプリ6箇所の版番号とworkflowの0.5.16限定ガード、対象コミットの変更範囲を確認します。
2. 型検査、JavaScript／Rustテストと表示確認を行います。
3. mainに対象コミットだけを反映し、署名workflowを `version=0.5.16`、`release_tag=v0.5.16`、`publish=false` で実行します。
4. インストーラー、隣接署名、latest.json、SHA256SUMS.txtの4ファイルをDraftから再取得し、埋め込み公開鍵での署名検証と同一バイト列を確認します。失敗した候補は公開しません。
5. 所有者の公開許可の範囲で、検証済みDraftをLatestへ公開し、公式フィードから4ファイルを再取得して再検証します。
6. アプリの更新画面は所有者が操作します。再起動後の版番号、サーバー一覧、プロフィール、設定の保持を確認します。配布ファイルの検証だけでインストール受入を完了扱いにしません。

## 販売との分離

`supportConfig.enabled=false` と `BILLING_ENABLED=false` を維持します。署名ビルド・配布は課金有効化の代わりではありません。日本の税務方針、販売国制御、本番の同一アカウントへの資格反映・契約管理の受入は別工程です。
