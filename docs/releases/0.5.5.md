# TomoNode 0.5.5

Improves server-side extension preflight checks for NeoForge and Fabric metadata.

## Changes

- Prefer metadata for the server's selected loader when a JAR contains multiple loader descriptors.
- Treat NeoForge optional, incompatible, and discouraged dependencies as non-required, and ignore client-only dependencies on dedicated servers.
- Inspect Fabric's explicitly bundled JARs, recognize `provides` aliases for dependency resolution, and evaluate Minecraft version alternatives without treating an unsupported Fabric range as a confirmed mismatch.
- Keep missing required dependencies as blocking findings.

The preflight reads archive metadata only. Actual game startup and multiplayer compatibility are not verified by this release change.
